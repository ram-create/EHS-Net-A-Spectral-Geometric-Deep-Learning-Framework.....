# EHS-Net-A-Spectral-Geometric-Deep-Learning-Framework.....
EHS-Net is a spectral-geometric deep learning framework for identifying macromolecular particles in cryo-electron tomography (cryo-ET) volumes. Low-dose imaging gives a very low signal-to-noise ratio a limited tilt range produces missing-wedge artifacts, and particles occur in arbitrary 3D orientations. Standard 3D CNNs are translation equivariant.
